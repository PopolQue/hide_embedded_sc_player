# Internationalization (i18n)

Currently, the SCPlayer UI strings are hardcoded in English. This guide explains how to translate the player for your local audience.

---

## 1. Translatable Strings

The following strings are currently found in `src/lib/SCPlayer.tsx`:

| Original String | Usage |
| :--- | :--- |
| `No track selected` | Shown when no song is playing. |
| `SoundCloud player unavailable...` | Error message if the API fails to load. |
| `Select playlist` | ARIA label for the dropdown. |
| `Playback progress` | ARIA label for the seek bar. |
| `Track list` | ARIA label for the slide-up panel. |
| `Previous track` | ARIA label for the back button. |
| `Next track` | ARIA label for the skip button. |
| `Currently playing` | ARIA label for the active track icon. |

---

## 2. How to Translate

### React Implementation

To translate the player, you can currently pass a `labels` object to a future version of the component, or manually update the strings in `SCPlayer.tsx`.

*Example of planned feature:*

```tsx
<SCPlayer 
  labels={{
    noTrack: "Kein Track ausgewählt",
    error: "SoundCloud Player nicht verfügbar",
    selectPlaylist: "Playlist wählen"
  }}
/>
```

### Standalone / Shell Implementation

You can search and replace the strings directly in `sc-player-standalone.js`. Since the file is small, this is a quick way to localize the player for a specific festival site.

---

## 3. Right-to-Left (RTL) Support

The player layout is built with Flexbox. While not explicitly optimized for RTL (like Arabic or Hebrew), you can reverse the layout via CSS:

```css
.sc-player__bar {
  flex-direction: row-reverse;
}

.sc-player__text {
  text-align: right;
}
```

## 4. Contributing Translations

If you have translated the player into your language, please share the labels in an issue! We are working on a built-in i18n system for version 1.0.
