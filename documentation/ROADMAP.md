# Project Roadmap

This document outlines the planned features and future direction for the SCPlayer.

---

## Phase 1: Core Stability (Current)

- [x] Persistent "Shell" architecture.
- [x] React and Standalone implementations.
- [x] Local metadata caching.
- [x] Comprehensive documentation suite.

## Phase 2: Enhanced UI/UX (Upcoming)

- [ ] **Audio Visualizers:** Add optional Canvas-based wave visualizers.
- [ ] **Volume Control:** Add a dedicated volume slider (currently relies on system/widget volume).
- [ ] **Search/Filter:** Allow users to search for tracks within large playlists.
- [ ] **Keyboard Global Shortcuts:** Support for media keys (Play/Pause/Next) via the `MediaSession` API.

## Phase 3: Advanced Integrations

- [ ] **WordPress Plugin:** Create a dedicated wrapper for easier WordPress setup.
- [ ] **Analytics Bridge:** Built-in support for Google Analytics 4 event tracking (Track starts, finishes).
- [ ] **Multi-Source Support:** Extend the architecture to support Mixcloud or YouTube Audio.

## Phase 4: Native & Performance

- [ ] **PWA Support:** Service Worker patterns for offline metadata.
- [ ] **Native Mobile Bridge:** Patterns for embedding the player in Capacitor or React Native WebViews.
- [ ] **Theming Engine:** A web-based "Theme Builder" to generate CSS variables visually.
